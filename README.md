## Documentation Notes

- Wild‑type CDS and protein sequences were recorded and translated.
  
- Documented mutation (F508del) was analyzed for CDS length, protein length, reading frame, and functional consequence.
  
- Artificial mutation (TCG deletion) was created and compared against wild‑type and F508del.
  
- Results were stored in Galaxy and exported to GitHub for reproducibility.
  
- Reference genome and annotation versions were documented in the README for transparency.
